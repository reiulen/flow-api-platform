# Genre Pack — Tech

Belum ditulis. Pack ini disusun setelah pilot militer lolos quality bar, mengikuti struktur `bibles/military/`:

- `GENRE.md`: override parameter, arti warna, block motion khas tech (diagram arsitektur, alur data, chip/hardware cutaway, UI/screen recording).
- `SOURCES.md`: sumber footage (press kit resmi, rekaman layar sendiri, arsip perusahaan, NASA/lab pemerintah) dan status lisensinya.
- `PRODUCT_QC.md`: checklist akurasi produk dan UI untuk shot Flow.

Sampai pack ini ada, topik tech tidak boleh masuk G1.
